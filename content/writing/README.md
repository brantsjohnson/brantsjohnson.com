# content/writing

Where Brant's writing comes from. Read `docs/PUBLISHING.md` first.

- `sources.ts` lists the newsletters (Substack feeds) the Writing page reads automatically.
- `articles.ts` holds extra details for articles that live on Substack (a cover, a summary, which Work or Events page it is about).
- Posts written **on this site** are markdown files in `content/posts/` (unlisted until their release day).
