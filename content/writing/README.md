# content/writing

This folder holds Brant's public writing for the Writing page.

- `posts.ts` is the list of pieces published on this site.
- When `SUBSTACK_URL` is set, the site also reads that publication's RSS feed.
- `essay` means a government reform essay published on this site.
- `newsletter` means a letter. If the letter also lives in a newsletter, set `canonicalUrl` and publish the mirror here one day after the original.
- Leave the list empty until a real piece exists. Do not add sample posts. The Writing page stays hidden while both this list and the Substack feed are empty.
