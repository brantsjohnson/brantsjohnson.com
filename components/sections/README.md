# components/sections

Page-level building blocks such as Hero, ProjectGrid, AboutBlock, and ContactForm. A section is opinionated about layout for one part of a page. If something is reusable everywhere, it belongs in `components/ui` instead.

- `Hero.tsx`: Home hero driven by referral variant copy (`docs/15-REFERRAL-SITE-VARIANTS.md`).
- `Now.tsx`: Bridger tastes panel on the home page.
