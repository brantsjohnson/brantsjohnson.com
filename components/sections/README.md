# components/sections

Page-level building blocks. A section is opinionated about layout for one part of a page. If something is reusable everywhere, it belongs in `components/ui` instead.

Current sections:

- `SiteHeader/` sticky glass bar: full name, the page links, and Ask about me.
- `SiteFooter.tsx` ink close, page links, and a cropped name. The email address is not repeated here.
- `PageHero.tsx` cream header with a large serif title.
- `BridgeMark.tsx` an unused bridge drawing. It is not on a page, and it is not Crew artwork.
